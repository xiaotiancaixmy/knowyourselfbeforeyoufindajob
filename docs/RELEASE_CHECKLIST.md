# Release Checklist

用于公开 GitHub 仓库、作品集演示或交给面试官评审前的检查清单。

## 自动检查

- [ ] `pnpm install --frozen-lockfile` 成功
- [ ] `pnpm check` 成功
- [ ] `pnpm test` 成功
- [ ] `pnpm build` 成功
- [ ] `pnpm audit --prod --audit-level high` 没有已知漏洞
- [ ] `python -m unittest discover -s tests` 成功
- [ ] API production build 可以启动并通过 `/api/health`
- [ ] GitHub Actions CI 通过

## 安全与隐私

- [ ] `.env`、API key、数据库和日志没有进入 Git
- [ ] 截图只使用虚构候选人和虚构公司数据
- [ ] README 没有包含真实简历、JD、对话或模型输出
- [ ] Git 历史没有可用的 token、私钥或账号凭据
- [ ] 结构化日志没有输出简历全文、完整 JD 或模型原始响应

## 产品验证

- [ ] 文本简历可导入并进入经历核对
- [ ] PDF 可显示解析中、成功和失败状态
- [ ] 重点经历可选择 1–3 段
- [ ] 补充事实对话可收到模型回复并防止重复提交
- [ ] 上一步修改后，下游资产会失效或要求重新确认
- [ ] 候选人画像与求职定位可以确认
- [ ] JD 文本和岗位截图都可进入岗位分析
- [ ] 分析失败后保留 JD，并可重新分析
- [ ] 建议投递时可以生成、保存和重新生成岗位版简历
- [ ] 页面在桌面端和移动端均可完成主流程

## 对外说明

- [ ] 明确这是本地单用户 MVP，而不是生产级多用户服务
- [ ] 明确 AI 介入点、用户确认点和不可编造原则
- [ ] 明确 DeepSeek 调用涉及的数据范围
- [ ] README 截图、启动方式和架构说明与当前代码一致
- [ ] 仓库链接使用可访问的默认分支
- [ ] 仓库可见性、许可证和安全报告方式已经确认
